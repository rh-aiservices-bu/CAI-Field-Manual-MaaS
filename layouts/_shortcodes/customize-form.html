{{- /* The "Customize this!" form: one control per choice — the variant axes (params.variants, an ordered slice) and every text field (params.customize). The variant buttons reuse the same group attribute the page-top selector wires, so the runtime persists them, filters content, and mirrors every group on the page. the text inputs read and write the same localStorage keys the pre-paint bootstrap (hooks/head-end.html) and the token runtime use. Variant buttons: clicking one sets the attribute (CSS does the content filtering), persists to 'td-variant:v1:', and mirrors every other button group on the page — including the page-top selector's, since mirrorVariant() walks the whole document. Text fields: typing updates 'td-customize:v1:' (debounced), the data-td-customize- attribute, and every token on every page via the storage/change event — no reload needed. Markdown and print outputs render the field list as plain text, so agents and print readers see the shipped defaults. */ -}} {{- $variants := site.Params.variants -}} {{- $fields := site.Params.customize -}} {{- $format := lower ($.Page.Store.Get "tdOutputFormat" | default "html") -}} {{- if and (not $variants) (not $fields) -}} {{- warnf "shortcode %q: neither params.variants nor params.customize is configured at %s" .Name .Position -}} {{- else if ne $format "html" -}} {{- /* Non-HTML outputs: list the fields and current defaults as text. */ -}} Choices this prototype remembers (set them on the Customize page; the HTML substitutes them everywhere). A variant block may list several options: {{- range $variants }} {{- $axisCfg := . }} {{- $axisName := .label | default .id }} {{- $defaultLabel := .default }} {{- range .options }}{{ if eq (printf "%v" .id) (printf "%v" $axisCfg.default) }}{{ $defaultLabel = .label }}{{ end }}{{ end }} - {{ $axisName }}: {{ range $i, $o := .options }}{{ if $i }}, {{ end }}{{ $o.label }}{{ end }} (default: {{ printf "%v" $defaultLabel }}) {{- end }} {{- range $fields }} - {{ .label | default .id }}: text (default: {{ .default }}) {{- end }} {{- else -}}

{{ .label | default $axis }}
{{- range .options }} {{- end }}
{{- end }} {{- end }} {{- range $fields }}
{{- end }}
{{- end -}}
