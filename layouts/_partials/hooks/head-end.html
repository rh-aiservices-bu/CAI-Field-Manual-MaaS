{{- /* Pre-paint display-option state: read the reader's stored choices from localStorage, set attributes, and emit the filter CSS before the stylesheet paints, so the first frame already matches. Mirrors the theme's own td-preset/td-color-theme bootstrap pattern in head.html. Axes come from params.variants; the filter rules are GENERATED from the config, not hand-written: for every axis, an active option hides every other option's blocks. An option id of `both` never hides anything and is never hidden, so html[data-td-variant-='both'] matches no rule and untagged content always renders. Storage-blocked readers keep the server-rendered defaults (no attribute, no filtering). */ -}} {{- $variants := site.Params.variants -}} {{- if reflect.IsMap $variants -}} {{- end -}}
