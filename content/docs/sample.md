Duplicate this page, retitle it, and fill in your own field procedures.

## Purpose {#purpose}

State what this procedure accomplishes and when to reach for it. Field pages lead with the outcome, not the background.

## Prerequisites {#prerequisites}

List what must be true before starting: access, tooling, environment state.

## Procedure {#procedure}

Numbered steps, one action per step, each verifiable.

1. Run the setup command and confirm the output matches expectations.
2. Apply the change.
3. Verify the result.

> [!TIP]
> Callouts capture field notes: gotchas, workarounds, and things that are only obvious in hindsight.

## Verification {#verification}

What the operator checks to confirm success before closing the ticket.

## Rollback {#rollback}

How to undo it cleanly when the procedure fails mid-flight.
